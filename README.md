# Global Superstore Data Analysis Using Power BI

## Project Overview

This project focuses on analyzing and visualizing retail business
data using Microsoft Power BI.

The Global Superstore dataset is used to explore sales, profit,
regional performance, product categories, and customer segments.

The objective is to transform raw data into meaningful business
insights through interactive dashboards and visual reports.

## Objectives

- Analyze overall sales and profitability.
- Compare sales performance across geographical markets.
- Identify top-performing products and categories.
- Analyze customer purchasing patterns.
- Build interactive Power BI dashboards.
- Support data-driven business decision-making.

## Tools and Technologies

- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX (Data Analysis Expressions)
- GitHub

## Project Workflow

1. Import the Global Superstore dataset.
2. Clean and prepare the data using Excel and Power Query.
3. Organize and model the data in Power BI.
4. Create calculated measures using DAX.
5. Develop charts, KPI cards, and map visualizations.
6. Analyze sales, profit, products, and regional performance.
7. Document the findings and business insights.

## Dashboard Features

- Sales and Profit Overview
- Regional Sales Analysis
- Product Category Analysis
- Customer Segment Analysis
- Geographical Profit Analysis
- Product Subcategory Performance
- Interactive Charts and KPI Cards

## Key Insights

The project report identifies Asia Pacific as the leading
sales market, followed by Europe.

The analysis also highlights differences in sales and
profitability across geographical markets and product
subcategories.

Consumer customers account for the largest share of
purchasing quantities in the reported analysis.

These findings can help businesses evaluate performance
and identify opportunities for improvement.

## Business Value

This project demonstrates how business intelligence and
data visualization can help organizations:

- Understand regional sales trends.
- Evaluate product performance.
- Compare revenue and profitability.
- Make informed business decisions.
